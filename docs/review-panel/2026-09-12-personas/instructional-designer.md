# Instructional Designer — Review of `docs/workshop-design.md`

**1. Two-tier gate: mostly holds, but two modules lean on weak Tier-1 items that Tier-2 doesn't reliably backstop.**

- **Module 08** ("Your First Agent") is the weakest row: of its checklist, the reason-for-choice, template name, knowledge source, and capability are all *presence-only* checks — a learner could type conforming labels without a functioning agent. It's rescued by exactly one item: the fact-string transcript + control-run pair, which genuinely can't be faked without having built and queried the agent. Remove that one item and Module 08 fails hands-on-by-design.
- **Module 03 is more concerning because it's the hard prerequisite for 04-08.** Its Tier-1 (structural markers, filename references, "before/after diff... checked for **presence** of required structural output," plus three **[self-attested]** save/schedule/share confirmations) never requires evidence the prompt was actually run against Copilot — a learner could hand-write conforming text and self-attest the rest. Tier-2 for this module only asks "would this prompt still work next week" (a judgment call), which doesn't catch "never executed." Since every later module inherits this prompt, the weakest link sits at the base of the arc.
- By contrast, Modules 01, 02, 06, and 07 genuinely enforce doing: hidden-key exact-string matches (planted errors, action items) and cell-traceable figures can't be satisfied by reading alone. §8's own honesty about Tier-1's provenance limit (screenshots are provenance-free) is accurate but doesn't fully cover 03/08's presence-only items.

**2. Kellerman & Castle: the cast is swappable; the industry setting is load-bearing; the "continuing story" doesn't actually compound.**

No Tier-1/Tier-2 check ever references a character by name — every mechanical check keys on data (strings, cell values, counts), so renaming Johnny/Molly/Dalton to generic labels breaks nothing. What *is* real: financial-services stakes justify Domain 1's responsible-AI weight (§5), and recurring roles give task-assignment shorthand. But §9's "one continuing story" claim overstates itself: Module 09 explicitly requires a "capstone-only fixture packet... not derivable from any Module 01-08 fixture" for the *same* Molly/Bodhi — new, disconnected facts each reappearance (02, 06, 07, 09), deliberately, to block resubmission gaming. So the troupe persists but the case file resets each time — recurring actors in unrelated scenes, not one accumulating case.
