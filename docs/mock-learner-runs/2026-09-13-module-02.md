# Mock Learner Gremlin dogfood run - Module 02, 2026-09-13

*Simulation only. Both attempts below are agent-produced role-play, not a real human learner's
work. This run tests whether Module 02's gate mechanism holds up against a genuinely blind
attempt - it does not, and cannot, prove anything about a real human's experience with this
module. See `~/hekton/gremlins/coaching/mock-learner-gremlin.md` for the Gremlin this run
dogfoods.*

## What this run is

The first real run of the Mock Learner Gremlin (v0, draft), against Module 02 (Trust, But
Verify). Two personas, each a fresh, isolated agent given only the module's public README
(truncated at its own stated commitment point - "write and save that memo before you read any
further") plus the two open fixtures (`molly-jensen-client-file.md`, `copilot-draft-summary.md`),
pasted directly into the prompt rather than granted repository file access. Neither persona was
ever given `fixtures/hidden/grading-key.md`, the dry-run artifacts, or any maintainer doc.

- **Priya Nandakumar** - diligent persona: methodical, reads fully, double-checks her own work.
- **Marcus Webb** - rushed persona: busy, skims, goes with a first plausible read, doesn't like
  re-checking twice.

Each persona wrote a verification memo cold, was then shown the module's own revealed self-check
table (the same reveal-after-commitment content a real learner sees after saving their memo) and
asked to grade itself honestly, and separately had its memo independently graded by a third,
isolated agent holding the real hidden key - blind to the self-check verdict.

## Results

| | Priya (diligent) | Marcus (rushed) |
|---|---|---|
| All 5 errors found, exact phrase | Yes | Yes |
| All 5 verification-method labels correct | Yes | Yes |
| All 5 corrections factually correct | Yes | Yes |
| Sensitive-data answer (both required facts) | Yes | Yes |
| Self-check verdict | Pass | Pass |
| Independent verification verdict | Pass | Pass |
| Self-check matched independent verdict | Yes | Yes |

Both personas passed, cleanly, on both the self-check and the independent check, with full
agreement between the two. No false positive or false negative in the self-check mechanism
surfaced in this run.

## The finding that actually matters: the rushed persona didn't fail

This is the headline result, and it is a finding about the **Gremlin's own design**, not about
Module 02. Marcus was briefed to skim, to take a first plausible read, and to skip re-checking -
and his own process notes said exactly that ("I gave this one real read-through... I didn't go
back and re-check the client file a second time"). His memo was still, on independent grading,
indistinguishable in quality from Priya's: same five errors, same five labels, same five
corrections, same two-part sensitive-data answer.

Marcus's own self-check reflection, unprompted, names the reason directly:

> "these five errors were pretty blatant once you had the client file fresh in your head... I got
> a clean result on an exercise that was, frankly, tuned to be catchable on one honest pass, not
> on a genuinely adversarial one."

This is a real, evidenced instance of a risk `mock-learner-gremlin.md` already named before this
run (Risks: "An agent persona is not a real human... does it default back toward being too
capable, too thorough"), now confirmed rather than hypothetical. Instructing an LLM to *play* a
careless persona did not produce a careless *attempt* at this task shape - a bounded, two-document
line-by-line comparison is exactly the kind of thing a language model does competently regardless
of the personality framing wrapped around it. This matches a lesson already established elsewhere
in this factory's own history, independent of this run: `borrow-native`'s and this workshop's own
"naive" dry-run attempts were never produced by asking an agent to act careless - they were
constructed by an author deliberately scripting one concrete mistake (a specific line dropped, a
specific figure left unrounded, a specific fund line pasted through unchanged). A personality
brief is not the same intervention as a scripted flaw, and this run is direct evidence they are
not interchangeable.

**This is not a negative result for Module 02.** It's a positive one, read correctly: the gate
turned out to be robust enough that ordinary, undramatic carelessness (one read-through, no
second pass) still produces a passing attempt, for this exercise's error set (a wrong figure, a
wrong date, a fabricated fund, a stale reference, a fabricated instruction - each large and
distinct rather than subtle). The gate wasn't tested against a genuinely adversarial or a
genuinely error-prone attempt in this run, because neither persona produced one.

## What this run does and doesn't prove

- **Proves:** a genuinely blind attempt, given only the module's public content and the exact
  discipline a real learner would need (read the client file first, compare line by line, commit
  before checking the reveal), can produce a fully correct memo without ever seeing the hidden
  key. This is real, positive evidence the earlier fix adding the two Purview facts up front
  (`docs/decisions.md`, 2026-09-13 consolidated pass) actually closed the unsatisfiable-checklist
  gap it was meant to close - a blind attempt that never saw the hidden key still landed both
  required facts.
- **Proves:** the self-check table's own wording is specific enough that an honest attempt
  checking itself against it reaches the same verdict a blind independent grader reaches - no
  daylight between the two in this run.
- **Does not prove:** that Module 02's gate would catch a genuinely careless or genuinely
  mistaken real human attempt, since this run never produced one. The "rushed" persona is not
  evidence either way on that question - see above.
- **Does not prove:** anything about a real human's actual experience, confusion, or time-on-task,
  since both attempts were agent role-play with no real UI, no real Copilot, and no real time
  pressure or distraction.

## Friction log (both personas)

Neither persona reported confusion about what to produce, where to find the fixtures, or how to
format the memo. Priya raised one substantive, honest uncertainty in her process notes: whether to
treat the Grace Okonkwo error as one combined claim or two separate ones (advisor name + tenure
claim) - she resolved it correctly (one continuous false claim) but flagged the ambiguity herself
before seeing the table's own explicit warning about exactly this. That the module's own written
warning ("Row 2 is worth reading twice...") anticipates a real point of confusion a blind attempt
independently hit is a good sign for that specific piece of module design, not a defect.

No other friction worth logging surfaced in this run.

## Methodological note for the Gremlin itself

Module 02's reveal-after-commitment table lives inline in the same public README as the exercise
instructions, gated by an honor-system "don't read past this line" - not in a separate withheld
file the way Modules 01/07/09's hidden keys are. True blindness for this shape of module was only
achievable because the orchestrator (not the Attempt Agent) controlled exactly what text was
pasted into the first prompt, truncating the README at its own stated commitment point and
revealing the rest only in a follow-up turn after the memo was already produced. Relying on an
agent's own restraint not to read past an inline marker would have been a materially weaker
control (`mock-learner-gremlin.md`'s own Design Principle 1: "an instruction not to peek is not a
control"). This should be named explicitly in the Gremlin's own procedure for any module whose
reveal lives inline rather than in a withheld file - see the definition update accompanying this
report.

## Cost, observed

Two Attempt Agent runs (~52-62s, ~30k tokens each) plus two follow-up self-check turns plus two
independent Verification Agent runs (~20-37s, ~30-37k tokens each) - roughly 6 agent turns, well
under half a minute each of wall clock and roughly 190k tokens total for one module, two personas,
full round trip. Consistent with the Risks section's cost caution, though cheaper in practice than
the Workshop Review Panel's seven-persona cost for a comparable single-module check.
