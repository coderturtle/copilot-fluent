## Documentation convention

This log is append-only. When a later decision changes or invalidates an earlier row,
add a new dated row rather than editing the old one, and name the superseded row
explicitly (e.g. "supersedes 2026-09-12 row on X"). `heartbeat`'s own decisions.md still
describes a site `base` path that its actual `astro.config.mjs` no longer uses, because
no superseding row was ever added when the config changed — this rule exists to not
repeat that.
